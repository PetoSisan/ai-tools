# Agent harness
- The agent harness is software layer **orchestrating the workflow** around AI's usage.
- It provides tools, context, permissions, and session state so that the AI model can perform **multi-step tasks**.
- see diagram from VS Code docs: https://code.visualstudio.com/docs/agents/concepts/agent-harnesses

## Agent loop
- see diagram from VS Code docs: https://code.visualstudio.com/docs/agents/concepts/agents#_agent-loop
- consists of 4 steps:
1. Understand
2. Act
3. Validate
4. Iterate
